# Contribuir

Este repositorio contiene una bitácora académica. Los cambios deben conservar la trazabilidad del proyecto y la privacidad de participantes y terceros.

## Flujo

1. Crea una rama descriptiva desde `main`.
2. Modifica contenido o código en el área correspondiente.
3. No subas `.env`, documentos originales, identificaciones, capturas privadas ni respuestas individuales.
4. Ejecuta `pnpm validate`.
5. Actualiza documentación y `CHANGELOG.md` cuando el cambio sea funcional o editorial.
6. Abre un pull request usando la plantilla.

## Contenido

No inventes resultados, participantes, citas ni evidencias. Usa los estados del esquema y marca explícitamente cualquier sección pendiente.

## Commits

Usa Conventional Commits en inglés, coherentes con el historial inicial del proyecto:

```text
feat(content): publish activity four draft
fix(a11y): improve mobile navigation label
docs(deployment): record Pages smoke test
```
