# ADR 0006: Identidad visual propia

## Estado

Aceptada

## Decisión

Construir un lenguaje de cuaderno de decisiones financieras y territorio, sin copiar el diseño institucional de UNIMINUTO.

## Por qué

La paleta petróleo, terracota, crema, carbón y dorado conecta con el brief y evita una plantilla bancaria o institucional genérica. `DESIGN.md` contiene las reglas durables.
