# Fuentes académicas locales

Esta carpeta reúne los documentos originales usados para preparar el contenido del blog:

- `semana-2-del-diagnostico-a-la-accion.pdf`
- `semana-4-decisiones-que-si-suman.pdf`
- `plan-responsabilidad-social-educacion-financiera.pdf`

Los archivos se mantienen fuera del repositorio mediante `.gitignore` porque pueden contener identificadores, metadatos de autoría u otra información académica privada. Por solicitud expresa del autor, el plan se copia también a `public/documents/plan-responsabilidad-social-educacion-financiera.pdf` y se etiqueta en el sitio como documento original académico; las otras fuentes siguen fuera de la publicación.
