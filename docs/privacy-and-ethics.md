# Privacidad y ética

- Los PDF fuente están organizados en `docs/fuentes-academicas/` y permanecen ignorados por Git porque contienen ID universitario, autoría y metadatos.
- El sitio solo muestra `José Carlos Gómez`, no el nombre completo salvo que el contexto académico lo requiera.
- No se almacenan respuestas individuales ni datos de clientes.
- El diagnóstico debe ser voluntario, anónimo y limitado a hábitos/conocimientos.
- La entrevista necesita consentimiento antes de grabar o publicar.
- Ejemplos numéricos se marcan como ficticios.
- Toda referencia externa conserva su atribución y se revisa antes de publicar.
- El texto aclara que el contenido es educativo y no asesoría personalizada.
- Los PDF públicos se reconstruyen sin ID universitario, nombres completos, firmas, historial, metadatos personales, logos no autorizados ni datos de terceros.
- Los originales no se publican, no se versionan y permanecen fuera de `public/`.
