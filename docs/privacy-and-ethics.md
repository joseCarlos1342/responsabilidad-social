# Privacidad y ética

- Los PDF y XLSX fuente están organizados en `docs/fuentes-academicas/` y permanecen ignorados por Git porque contienen autoría, metadatos o registros individuales.
- El sitio solo muestra `José Carlos Gómez`, no el nombre completo salvo que el contexto académico lo requiera.
- Las respuestas individuales se conservan únicamente en fuentes locales ignoradas; no se versionan, publican ni incluyen en el bundle.
- El diagnóstico debe ser voluntario, anónimo y limitado a hábitos/conocimientos.
- La entrevista cuenta con autorización audiovisual verificada para grabación y uso de fragmentos con fines académicos y educativos. Se publica una copia MP4 optimizada sin metadatos; el MOV fuente permanece fuera de `public/`.
- Ejemplos numéricos se marcan como ficticios.
- Toda referencia externa conserva su atribución y se revisa antes de publicar.
- El texto aclara que el contenido es educativo y no asesoría personalizada.
- Los documentos públicos son ediciones agregadas o archivos académicos originales autorizados y claramente identificados como tales.
- `Decisiones que suman.xlsx` y el reporte posterior se generan con conteos y porcentajes agregados: no incluyen filas individuales, edades ni marcas temporales. Los XLSX brutos y el MOV original se conservan fuera de `public/` y no forman parte del bundle web.
- `Pruebas.pdf` y la captura de Teams se retiraron de `public/` por contener nombres, perfiles, enlaces privados o identificadores. Solo se publican estadísticas agregadas.
- La encuesta final usa Google Forms, es voluntaria, no solicita datos personales ni financieros y se enlaza junto con el aviso de tratamiento agregado y la política del proveedor externo.
- Una versión bruta del XLSX inicial estuvo presente en el historial Git anterior a esta corrección. Su purga requiere autorización para reescribir el historial y coordinar el remoto; hasta entonces se registra como riesgo histórico pendiente.
